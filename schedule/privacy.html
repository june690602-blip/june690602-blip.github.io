개인정보처리방침

시행일 2026년 10월 26일

이 방침은 일정관리 비서의 PC 위젯(Windows)과 안드로이드 앱(아래 '앱'), 그리고 이 누리집에 적용됩니다.

한눈에
  • 사용자가 쓴 일정 · 할 일 · 기록은 사용자의 기기와 사용자가 고른 저장 공간(동기화 폴더 또는 사용자 본인의 구글 드라이브)에만 저장됩니다.
  • 개발자는 서버를 두지 않으며, 사용자의 일정이나 계정 정보를 받지 않습니다.
  • 광고, 사용 통계, 분석 도구, 오류 수집 도구는 없습니다.
  • 구글 권한은 이 앱이 만든 것만 다루는 drive.appdata, drive.file 두 가지이며, 사용자가 켤 때만 묻습니다.

2구글 사용자 데이터

구글 연결은 선택 기능입니다. 사용자가 설정에서 켤 때 구글 로그인 화면이 열리고, 아래 권한만 요청합니다.

권한읽고 쓰는 것쓰는 목적
drive.appdata 드라이브의 숨김 앱 폴더 안, 이 앱이 만든 기기별 동기화 파일(sync-<기기 ID>.json) PC와 폰의 일정 · 할 일 · 기록을 맞추기
drive.file 이 앱이 만든 구글 시트 한 장('일정관리 비서 · Claude 연동') 사용자가 claude.ai의 Claude와 이 시트로 일정 · 할 일을 주고받기(PC 위젯 전용)

두 권한 모두 이 앱이 만든 파일만 다룰 수 있습니다. 앱은 사용자의 다른 드라이브 파일, 메일, 캘린더, 연락처를 볼 수 없습니다. 연결된 계정을 보여 주려고 드라이브 정보에서 계정 메일 주소를 읽습니다.

  • 구글에서 받은 데이터는 위 기능을 사용자에게 제공하는 데만 씁니다.
  • 개발자나 다른 사람에게 보내지 않고, 팔지 않으며, 광고나 맞춤 광고에 쓰지 않습니다.
  • 사람이 그 내용을 읽지 않습니다. 앱이 사용자의 기기 안에서 처리합니다.
  • 인공지능 모델을 학습시키는 데 쓰지 않습니다.

일정관리 비서가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한된 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

앱은 아래 서비스에만 직접 연결합니다. 인터넷 요청이라 각 서비스는 기기의 IP 주소를 볼 수 있습니다.

폴더 동기화를 고르면, 그 폴더를 옮기는 서비스(OneDrive 등)는 사용자가 쓰는 서비스이며 그 서비스의 방침을 따릅니다. PC 위젯의 'Claude 연결(MCP)'을 사용자가 직접 등록하면, Claude는 이 PC의 일정 파일을 읽고 일정을 넣을 수 있습니다. 이때 Claude에게 보낸 내용은 사용자가 쓰는 Claude 서비스의 방침을 따릅니다. 메일로 보내기 같은 버튼은 사용자의 브라우저에서 Gmail 쓰기 화면을 열 뿐이며, 보내기는 사용자가 직접 합니다.

4제3자 제공과 처리 위탁

개발자는 사용자의 개인정보를 받지 않으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다.

5보관 기간과 지우는 법

  • 기기 안의 정보 — 사용자가 지우거나 앱을 지울 때까지 남습니다. 앱 안에서 일정 · 할 일을 지우면 다른 기기에도 지워졌다고 전해집니다.
  • 드라이브 숨김 앱 폴더 — 구글 드라이브 웹 › 설정 › 앱 관리 › '일정관리 비서' › 숨겨진 앱 데이터 삭제.
  • Claude 연동 시트 — 사용자 드라이브에서 그 시트를 지우면 됩니다.
  • 구글 권한 — 앱 설정의 '끊기'는 그 기기만 끊습니다. 권한을 완전히 거두려면 구글 계정 › 서드 파티 연결에서 '일정관리 비서'를 삭제합니다. 그러면 모든 기기의 구글 연결이 함께 끊깁니다.

6사용자의 권리

모든 정보가 사용자의 기기와 사용자 본인의 계정에 있으므로, 사용자는 언제든 직접 열람 · 고치기 · 지우기 · 처리 멈추기(동기화 끄기, 권한 거두기)를 할 수 있습니다. 도움이 필요하면 아래 문의처로 알려 주세요.

7안전을 위한 조치

  • 바깥 서비스와는 모두 HTTPS로 연결합니다.
  • PC 구글 로그인은 PKCE 방식을 쓰고, 로그인하는 동안만 이 컴퓨터 안의 주소(127.0.0.1)를 잠깐 엽니다.
  • PC의 구글 로그인 정보는 운영체제 암호화로 싸서 저장합니다.
  • PC 위젯의 화면 쪽 코드는 인터넷에 연결할 수 없게 막아 두었습니다.

8쿠키와 이 누리집

앱과 이 누리집은 쿠키, 분석 도구, 바깥 글꼴 · 스크립트를 쓰지 않습니다. 이 누리집은 GitHub Pages로 운영되며, GitHub이 보안을 위해 접속 기록(IP 주소 등)을 남길 수 있습니다(GitHub 개인정보처리방침).

9어린이

앱은 어린이를 대상으로 하지 않으며, 개발자는 누구의 개인정보도 받지 않습니다.

10방침이 바뀔 때

바뀌면 이 페이지에 새 내용과 시행일을 올립니다. 사용자에게 불리하게 바뀌는 경우에는 시행 7일 전부터 이 페이지에 미리 알립니다.
